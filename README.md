# FinanceTracker
A Python desktop app for managing income and creating custom budgets. Users can input their salary, generate suggested budgets, and track purchases using dynamic tables. I built this to strengthen my skills in Tkinter and Matplotlib while learning how to structure a real-world Python project.
Expense entries are appended to `Expenses.csv`. The Reset All Data action clears the contents of both `Expenses.csv` and `Budgets.csv` and removes the displayed expense and budget entries.
Before clearing the files and displayed entries, Reset All Data asks for confirmation and warns that the action cannot be undone.
